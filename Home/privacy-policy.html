AgentZero Lite — Privacy Policy

Last updated: 2026-10-30

AgentZero Lite (“the app”) is a desktop shell for command-line AI tools. It is open source: github.com/psmon/AgentZeroLite.

What the app collects

Nothing is collected by the developer. The app has no accounts, no analytics, no telemetry and no crash reporting service. The developer does not receive any data from the app.

What the app stores on your computer

Workspaces, terminal layouts, settings, conversation history of the built-in assistant, downloaded models and logs are stored only on your computer. API keys you enter are encrypted at rest with Windows DPAPI (tied to your Windows account).

  • Microsoft Store edition: in the app’s own package storage, which Windows removes when you uninstall the app.
  • Edition installed from GitHub: under %LOCALAPPDATA%\AgentZeroLite\. Uninstalling does not delete this folder; you can delete it yourself.

Files of other programs the app reads, on your computer only: to offer resuming a conversation and to show whether an agent is working, the app reads the session and status files Claude Code, Codex and Hermes Agent keep in your user folder (.claude and Claude’s profile folders such as .claude-<name>, .codex, and Hermes’ folder — %LOCALAPPDATA%\hermes or ~/.hermes — whose conversation database is opened read-only) and the list of running processes (to find which terminal an agent runs in); to show git worktrees, it reads a workspace’s .git folder; and the code view’s GIT LOG tab runs your installed git program in the workspace folder (git log, read-only, no network) to list its recent commits — subject, message, author and date; the DIFF tab runs it the same way (git diff, git ls-files) to show the folder’s changes and new files. To estimate what the agents have cost (Settings → Budget), the app reads the token counts Claude Code and Codex record in their session files. Nothing from them leaves your computer.

What plugins can see: a plugin you open on the Plugins page can ask the app for the list of your workspaces (name and folder) and their running terminals (tab name, which agent it runs, and whether it is working, waiting or done) — the Agent Stage plugin uses this to draw them. For a Claude Code terminal the list also names the sub-agents its conversation is running or just finished: each one's type, the task it was given, the last tool it called with a short hint (such as a file name or the command's description), how many tools it has called and when it started and ended. The app reads these from the session records Claude Code keeps on your computer (~/.claude/projects/…/subagents/), only while that terminal is open. The plugin runs inside the app; the app itself sends this list nowhere.

Programs you run inside the app’s terminal tabs (for example Claude Code, Codex, agent-one, netclaw or Hermes) are separate software with their own privacy policies; the app does not see or forward their traffic.

Microphone and system audio

Only when you start it: in a plugin (for example Voice Note or Agent Band), with the microphone button of the assistant, or with "Listen live" in Settings → Voice. The app then listens to the microphone or to what your speakers play, turns it into text or labels on your computer (streaming speech recognition, Whisper, the AudioSet classifier, speaker labels), and shows the result there — the assistant's microphone puts the text in its input box and sends it as if you had typed it. No recording is kept. If you chose the OpenAI provider for speech recognition, the speech is sent to OpenAI to be transcribed. Stopping the plugin or pressing the microphone button again stops the capture.

Children

The app is a developer tool and is not directed at children.
