# M0038 수행결과 — 설정

## 수행 요약

계획 Phase 6을 구현했다. 좌측 내비(LLM / CLI definitions / Terminal)와 `SettingsViewModel`. 모든 저장소는 WPF와 공용이다:
`LlmSettingsStore`(External 공급자·모델·MaxTokens·Temperature·키/URL; 키는 `SecretProtection`으로 보호되어 저장 — Windows DPAPI 사본,
macOS AES-GCM), `AppDbContext.CliDefinitions`(CRUD, built-in 삭제 불가, 정렬, 실행 파일/키 파일 피커, 새 비밀번호만 보호해 저장하고
입력 없으면 기존 암호문 유지), `TerminalSettingsStore`(폰트·크기·행간·테마·커서·WebGL, 저장 시 열린 렌더러 전부에 `config` 재전송).
Windows에서는 Local 라디오·카탈로그·CPU/Vulkan·장치·다운로드·Load/Unload; 비Windows는 Local 비활성 + 툴팁.

### 결정

- CLI 정의 목록은 이 OS에서 실행 가능한 것만 보여 준다(`IsAvailableOnThisOs`). macOS에서 `.exe` 정의는 숨겨지되 DB에는 남아
  Windows 호스트가 그대로 쓴다. SSH 필드는 1차 범위상 Windows에서만 편집 가능.
- "Test connection"은 먼저 저장하고 `LlmGateway.OpenSession()`으로 실제 왕복한다(45 s 한도) — 설정 파일을 두 호스트가 공유하므로
  게이트웨이가 읽는 것과 같은 값을 시험하는 것이 맞다.
