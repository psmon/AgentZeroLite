# M0033 수행결과 — ZeroCommon 플랫폼 seam

## 수행 요약

계획 Phase 1 표(1.1~1.11)를 그대로 구현했다. 모두 **추가**이거나 `OperatingSystem.IsWindows()` 분기이며,
WPF 호출 경로의 Windows 동작은 바뀌지 않았다(`git diff --stat main -- Project/AgentZeroWpf` 비어 있음).

## 결과

| # | 심 | 비고 |
|---|---|---|
| 1.1 | `AppPaths` | 모든 OS에서 `LocalApplicationData/AgentZeroLite`; 기존 스토어는 무변경 |
| 1.2 | `ISingleInstanceGuard` | Windows 뮤텍스는 WPF와 같은 이름(두 GUI 동시 실행 금지), Unix 잠금 파일 |
| 1.3 | `ICliIpcBridge` | NamedPipe(`AgentZeroLite.cli`, CurrentUserOnly), 비동기 핸들러가 accept 루프 밖에서 실행, 1 MiB 캡(클라이언트·서버 양쪽) |
| 1.4 | `IConsoleTabInfo.Session/IsTerminalStarted`, `TerminalCatalogJson` | WPF `ConsoleTabInfo`가 이미 가진 멤버라 WPF 무편집 컴파일 |
| 1.5 | `TerminalEnvironment.BuildPosix/PrependPath` | 대소문자 구분, `TERM`/`LANG` 기본 |
| 1.6 | `TerminalLaunchPlanner`/`CommandLineSplitter` | `.exe`↔POSIX 경로 OS별 숨김, PATH 구분자는 대상 OS 기준 |
| 1.7 | `AppDbContext` 옵션 생성자 + OS별 런타임 시드 | 마이그레이션 없음; 비Windows에서 zsh/bash/Claude 1회 |
| 1.8 | LLM 울타리 | `_putenv_s`·Vulkan·llama.dll·Local 가용성 비Windows 안전 |
| 1.9 | `IPtyHost` + `XtermTerminalSession` + `TerminalHealthTracker` | WPF 세션 사본; Porta.Pty는 ZeroCommon 밖 |
| 1.10 | `AesGcmFileSecretProtector` | 현행 `ISecretProtector` 계약(마커·멱등·평문 통과) |
| 1.11 | `Agents/ChatModeCycle` | WPF 사본 |
