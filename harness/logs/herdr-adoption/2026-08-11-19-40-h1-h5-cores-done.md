# herdr 영입 — H1~H5 순수 코어 완료

## 실행 요약

herdr(Rust ADE)의 에이전트-상태 1급화 아이디어 5종을 AgentZero에 영입. 순수 로직은
ZeroCommon(헤드리스), CLI/WPF 글루는 분리. 참조본 `E:\git-other\herdr`.

## 결과

- **H1 상태 감지** — `AgentStateDetector`(순수 규칙 엔진) + `AgentManifestCatalog`
  (claude/codex/generic). region(full/bottom/osc) + contains/regex/any/not + priority +
  skip_state_update + explain(matched rule). 훅 없는 CLI도 커버(ApprovalParser blocked와 상보). **12 테스트**.
- **H2 롤업** — `AgentStateRollup`: Blocked>Working>unseen Done>Idle 집계 + NeedsAttention/
  AttentionCount. 미확인 done 강조. (14 테스트 중 롤업분)
- **H3 세션 복원** — `AgentResumeCatalog`: CLI별 resume 커맨드(claude --resume/codex resume/
  cursor-agent --resume/opencode --session/copilot --resume= 등) + 세션ID 주입 방지 regex. (resume분)
- **H5 wait --until** — `-cli terminal-wait --until <working|blocked|idle|done> [--agent N] [--stall-ms N]`
  → H1 감지로 상태 도달까지 대기 + stall 가드(무변화 시 종료). CLI 글루.
- **H4 권위 우선순위** — `AgentIntegrationCatalog`: SessionIdentity(화면이 상태 권위) vs
  LifecycleAuthority(훅 설치 시 화면 억제). `UseScreenDetection(agent, hookInstalled)`. **5 테스트**.
