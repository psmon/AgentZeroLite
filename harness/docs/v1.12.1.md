## The `tools/agent-band-tests/` harness

- Zero dependencies — Node 18+ built-in `node:test`. Run: `cd tools/agent-band-tests && node --test`.
- Placed in top-level `tools/` on purpose: `Wasm/**` is bundled into app output
  and `Project/Plugins/agent-band/` is under a 200-file install cap, so a test
  folder in either would ship inside the product.
- `pure.mjs` is a **hand-aligned reference copy** of `parseVideoId` /
  `labelToPerformer` (the plugin IIFE isn't importable) — same mirror
  convention the repo uses for `parseVideoId` (JS) ↔ `ParseYouTubeId` (C#).
  Editing the plugin regex requires updating pure.mjs + the mapping doc in the
  same commit; the tests then guard against silent drift.
